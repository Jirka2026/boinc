# BOINC Xbox v0.2.2 - Direct HTTP transport

Network diagnostics in v0.2.1 showed:

- direct TCP by IP works
- DNS hostname resolution works
- outbound TCP by hostname works

The remaining failure is therefore isolated to the HTTP transport layer.

Version 0.2.2 creates an explicit Windows.Web.Http.Filters.HttpBaseProtocolFilter and sets:

`UseProxy = false`

BOINC project requests now use a direct HTTP(S) connection rather than automatic proxy/WPAD discovery.

This is a diagnostic and compatibility change for Xbox Developer Mode.
