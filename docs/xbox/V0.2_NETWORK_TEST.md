# BOINC Xbox v0.2 - Network / Project test

## Scope

Version 0.2 validates the next layer of the Xbox port before integrating the full BOINC core client.

The app now displays:

- Xbox BOINC platform identifier
- CPU thread count visible to the UWP process
- current UWP application memory limit
- network connectivity state
- application-local data folder

It also provides a BOINC project URL field and a **Connect / Test project** button.

## Network test

The test normalizes the entered project URL and requests:

`<project URL>/get_project_config.php`

The response is displayed in the on-screen log. A response containing a BOINC project configuration root element is marked as recognized.

The last project URL is persisted in UWP local settings.

## Deliberate limitation

This milestone does not yet attach the Xbox to a BOINC account, contact the BOINC scheduler, download work units, or execute science applications.

The purpose is to validate:

`Xbox -> HTTPS -> BOINC project server -> response parsing/logging`

before importing larger parts of the BOINC client.
