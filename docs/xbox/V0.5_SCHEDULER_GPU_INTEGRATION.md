# BOINC Xbox v0.5 - Scheduler + CPU/GPU integration

This build combines multiple milestones into one Xbox test package.

## Test pipeline

1. Fetch and parse `get_project_config.php`.
2. Cache the downloaded project configuration in LocalState.
3. Fetch the project master page and discover the BOINC scheduler URL.
4. Verify TCP connectivity to the scheduler.
5. If email/password are entered, call `lookup_account.php` using the BOINC `MD5(password + email)` password hash. The plaintext password is never persisted.
6. Store/reuse the returned authenticator through `PasswordVault`.
7. Send a real BOINC scheduler request using platform `x86_64-pc-xbox-uwp`.
8. Parse scheduler reply, host ID, server messages, apps, app versions, workunits, results and file-info records.
9. Run a CPU throughput test using every logical processor visible to the UWP runtime.
10. Create a hardware Direct3D device plus structured compute buffer/UAV and report adapter + feature level.
11. Report the current UWP memory limit and local persistence status.

## Notes

The GPU check validates that Direct3D hardware compute resources can be created. It is not yet a science-application GPU benchmark or a dispatched compute shader.

The scheduler request intentionally asks for only a minimal amount of CPU work. Its purpose is to observe how a real BOINC scheduler responds to the Xbox platform before a project-specific science application is ported.

If no project account credentials or stored authenticator are available, account login and scheduler RPC are reported as SKIP while the other tests still run.
