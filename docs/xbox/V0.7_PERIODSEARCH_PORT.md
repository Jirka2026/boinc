# BOINC Xbox v0.7 - Asteroids PeriodSearch science port

v0.7 adds the real Asteroids@home PeriodSearch pure CPU science engine to the Xbox Series X UWP build.

Upstream source:
- repository: `AsteroidsAtHome/PeriodSearch`
- pinned commit: `ecd7f1dccb97acc3290a58f3920c9b1aa3a23656`
- source: `period_search_pure_cpu_win/period_search`

The upstream repository is linked as `xbox/third_party/PeriodSearch`.

## Architecture

The original `period_search_BOINC.cpp` and its numerical C sources are compiled into the Xbox package. A small compatibility layer maps the BOINC science-app calls used by PeriodSearch to the Xbox UWP LocalState sandbox: logical input/output filenames, `MFILE`, fraction reporting, BOINC init/finish, file rename/open and checkpoint API stubs.

The numerical solver is not replaced by a synthetic implementation.

## v0.7 validation workload

The package contains the official upstream `period_search_in` sample. The Xbox self-test changes only two workload parameters before execution:
- period end is set equal to period start, producing one period candidate;
- optimizer stop condition is reduced to two iterations.

This makes the first console validation practical while executing the original inversion, pole search, shape/scattering, matrix and brightness code paths.

The resulting `period_search_out` is written to the app LocalState directory.

## Production path

After the solver validates on Xbox, the same `periodsearch_run()` wrapper can execute a downloaded BOINC `period_search_in` workunit. The next stage is anonymous-platform app negotiation, real work download, result upload and scheduler reporting.
