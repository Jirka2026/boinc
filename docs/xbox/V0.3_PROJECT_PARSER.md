# BOINC Xbox v0.3 - Project parser

Version 0.3 converts the successful project configuration request into structured BOINC state.

## Added

- Project name parsing
- Master URL parsing
- Server version parsing
- Supported platform enumeration
- Native Xbox platform check for `x86_64-pc-xbox-uwp`
- Persistent project metadata in UWP local settings
- Project summary panel instead of dumping raw XML
- Runtime compute policy display

## Resource policy

The client is designed to use the maximum compute resources granted by the Xbox runtime.

For the current package, the runtime reports the visible logical processor count and the current application memory limit. The planned worker pool targets all visible CPU execution resources. Memory allocations use a 90 percent high-water mark so the process retains safety headroom and avoids termination at the hard UWP memory cap.

GPU compute will be added as a separate DirectX compute backend after the CPU science-worker path is operational.
