# BOINC Xbox v0.2.1 - Network diagnostics

This revision isolates Xbox UWP networking failures before BOINC protocol work continues.

## Added diagnostics

The app now tests:

1. UWP network profile state.
2. Direct outbound TCP to `1.1.1.1:443` using a literal IP address.
3. TCP to `one.one.one.one:443` using DNS name resolution.
4. BOINC project HTTP(S) requests with HRESULT logging.

Interpretation:

- Direct IP fails: outbound networking is blocked or unavailable to the app.
- Direct IP passes but hostname fails: DNS/name resolution is the problem.
- Both pass: the Xbox network stack is usable and the BOINC URL/request layer should be investigated next.

## UI

The fixed 1040-pixel panel was replaced with a safe-area layout and larger side margins for TV overscan.

## Capabilities

The package now declares `internetClient`, `internetClientServer`, and `privateNetworkClientServer`. Microsoft Xbox/UWP samples commonly declare the broader internet capability set while testing network scenarios.
