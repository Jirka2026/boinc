# BOINC Xbox v0.6 - Negotiation + performance integration

This build combines protocol diagnostics and runtime performance tests in one Xbox deployment.

## BOINC protocol tests

- Project configuration and scheduler discovery
- Account authenticator load/login
- Primary scheduler RPC using `x86_64-pc-xbox-uwp`
- Full primary scheduler reply cached as `v06_scheduler_primary.xml`
- Server `message`, `error_msg`, and `request_delay` diagnostics
- Safe alternate-platform probe using `windows_x86_64` with zero work requested
- Anonymous-platform probe with zero work requested
- Alternate and anonymous replies cached as `v06_scheduler_alt.xml` and `v06_scheduler_anonymous.xml`

The alternate-platform probe does not request work. It only tests scheduler negotiation behavior and must not be treated as proof that a Windows desktop science binary can run in Xbox UWP.

## Performance tests

- CPU scaling test at 1, 2, 4, 6, and 8 visible workers where available
- Memory commit test up to 70 percent of the runtime application limit
- Real Direct3D 11 compute shader dispatch using `ComputeBench.hlsl`
- GPU result verification by readback
- GPU throughput reported in Gupdates/s

## Current target

The current Xbox package remains a UWP app and the observed runtime memory limit is 1024 MB. The test reports what the runtime actually exposes rather than assuming retail Xbox hardware resources are fully available.
